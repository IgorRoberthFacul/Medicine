Um estudo sobre modularização de código com Node.Js.
Com alguns modulos externos: 
1. Express: Framework minimalista para Node.js que facilita a criação de servidores web e APIs.
2. Body-parser: Middleware que facilita a leitura de dados enviados no corpo da requisição (como dados JSON ou formulários).
3. Cors: Middleware para habilitar CORS (Cross-Origin Resource Sharing), permitindo que frontend se comunique com o backend de diferentes origens.
4. Jsonwebtoken: Biblioteca para criar e verificar tokens JWT (JSON Web Token), usada para autenticação e autorização.
5. Mongoose: Biblioteca ODM (Object Data Modeling) para MongoDB, que facilita a interação com o banco de dados MongoDB em Node.js.

Módulos Internos:
1. FS para manipulação de arquivos
2. HTTP para criar servidores web e path para trabalhar com caminhos de arquivos.
